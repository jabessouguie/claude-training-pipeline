## Usage

L'atelier 2 n'a pas de corpus de données dédié : il part directement du canevas d'opportunité produit à l'atelier 1 (voir [../atelier-1/](../atelier-1/)). Les stagiaires y challengent leur opportunité (Devil's Advocate), rédigent un mini-PRD et des user stories Gherkin validées par la checklist INVEST.

La solution suggérée et le guide de vérification sont dans [../solutions/solution-atelier-2.md](../solutions/solution-atelier-2.md).
