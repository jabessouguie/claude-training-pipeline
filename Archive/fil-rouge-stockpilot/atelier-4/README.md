## Usage

Support de l'atelier 4 (« Lancement simulé ») : les stagiaires ingèrent `metriques-j30-stockpilot.md` dans Copilot pour produire une synthèse sentiment × thème, identifier les signaux préoccupants et encourageants, puis trancher — Pivot or Persevere — en citant les données.

Les métriques sont construites pour être **ambivalentes** : les deux décisions (pivoter ou persévérer) sont défendables selon la lecture (globale vs par segment). La solution suggérée et le guide de vérification sont dans [../solutions/solution-atelier-4.md](../solutions/solution-atelier-4.md).
