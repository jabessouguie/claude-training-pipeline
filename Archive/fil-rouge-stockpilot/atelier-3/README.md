# atelier-3/ — Prototype de secours

## Fichiers

| Fichier | Format | Contenu |
|---|---|---|
| **enonce-atelier-3.pdf** | PDF (charte par défaut) | Énoncé imprimable de l'atelier : contexte, objectif, consigne, critères de réussite, indices et bonus |
| **enonce-atelier-3.html** | HTML | Source du PDF ci-dessus (à éditer puis regénérer si le contenu change) |
| **prototype-fallback.html** | HTML | Prototype monofichier fonctionnel de StockPilot (recherche de matériel, fiche équipement, réservation), prêt à l'emploi |

## Usage du prototype de secours

`prototype-fallback.html` est le **plan B** de l'atelier 3 et de la démo live du module 2 : si la génération du prototype par Copilot échoue ou tronque le code en séance, le formateur bascule sur ce fichier pour continuer la démonstration ou dépanner un binôme en difficulté.

Il n'est **pas destiné aux stagiaires en temps normal** — l'objectif de l'atelier est qu'ils génèrent eux-mêmes leur prototype.

La solution suggérée et le guide de vérification sont dans [../solutions/solution-atelier-3.md](../solutions/solution-atelier-3.md).

⚠️ Prototype fictif à des fins pédagogiques — à ne jamais brancher sur des données réelles.
