# Installation

**Les skills ne se synchronisent PAS automatiquement entre surfaces** (Claude Code, application Claude, Cowork) — c'est une contrainte du produit Anthropic : chaque surface a son propre mécanisme d'installation, et il faut répéter l'installation sur chaque surface qu'on veut utiliser.

**Choisis la page correspondant à l'outil que tu utilises** — tu n'as besoin de lire qu'une seule des trois :

| Tu utilises… | Va sur… |
|---|---|
| Claude Code (VS Code, Antigravity, ou ligne de commande) | [Installation — Claude Code](01-Claude-Code) |
| L'application Claude (claude.ai, app desktop/mobile) | [Installation — Application Claude](02-Application-Claude) |
| Claude Cowork | [Installation — Cowork](03-Cowork) |

Si tu utilises plusieurs de ces outils, répète l'installation sur chacun — voir la page correspondante.
