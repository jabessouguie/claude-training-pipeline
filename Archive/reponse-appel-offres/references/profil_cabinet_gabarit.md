# Gabarit — Profil cabinet

Ce gabarit est une **structure vide**, jamais pré-remplie avec un nom de cabinet supposé. Le cabinet réel varie selon le consultant et la mission : ne jamais assumer un nom par défaut (y compris un nom déjà vu dans un échange antérieur ou dans un autre workspace).

À l'Étape 3 de `reponse-appel-offres/SKILL.md`, ce gabarit est recopié et rempli interactivement avec le consultant dans le workspace de l'AO en cours (`appels-offres/<client>-<objet>/<AAAA-MM>/profil-cabinet.md`) — jamais à la racine du dépôt, jamais deviné.

```markdown
# Profil cabinet — <Nom du cabinet>

*Dernière mise à jour : <date> — à revalider si un champ semble périmé avant réutilisation sur un nouvel AO.*

## Identité
- Nom légal / commercial du cabinet :
- Statut juridique, taille (nombre de consultants), ancienneté :

## Domaines d'expertise
- <Liste des domaines de conseil/expertise, par ordre de maturité/profondeur>

## Méthodologies propres
- <Méthodologies ou frameworks propriétaires — nom + description courte>
- <Outils/accélérateurs internes réutilisables d'une mission à l'autre>

## Secteurs déjà servis
- <Liste des secteurs clients, avec ancienneté approximative si connue — sert de base à la sélection de références, Étape 5>

## Mode de fonctionnement
- Taille d'équipe typique mobilisée sur une mission :
- Modalités (régie, forfait, mixte) :
- Zones géographiques d'intervention :

## Différenciateurs
- <Ce qui distingue le cabinet de la concurrence sur ce type de marché — réutilisé dans la slide APPROCHE, Étape 6>

## Limites connues / zones de vigilance
- <Domaines où le cabinet est moins mature — utile pour ne jamais survendre un fit qui n'existe pas>
```

## Règles de remplissage (rappel pour l'agent qui exécute l'Étape 3)

- Chaque section est remplie avec ce que le consultant fournit explicitement, jamais deviné ni déduit d'une recherche web sur un cabinet supposé.
- Une section que le consultant ne peut pas renseigner sur le moment est marquée `<non renseigné>` plutôt que laissée vide silencieusement ou complétée par une supposition plausible.
- Si le consultant indique disposer d'un `profil-cabinet.md` déjà rempli pour un AO précédent, proposer de le réutiliser (après confirmation explicite) plutôt que de tout resaisir — mais toujours comme une copie dans le nouveau workspace, jamais un lien ou une référence partagée entre deux dossiers clients différents.
